# yMapper

**yMapper** — биоинформатический инструмент для автоматического построения, фильтрации и анализа интерактивных
гексагональных карт таксономического разнообразия мутаций Y-хромосомы (Y-SNP). Метод визуализации помогает локализовать
историческую область происхождения и пути миграции генетических популяций.

---

## Общие настройки

* **UI Lat / Lng:** Ручное позиционирование и центрирование карты по географическим координатам.
* **Grid size (0–6):** Масштабирование размера гексагональных ячеек (от детального локального анализа до
  макро-гексагонов).
* **Confirmed / Confirmed + Predicted:** Переключение между строго подтвержденными SNP и расширенной выборкой на основе
  предсказаний алгоритмов машинного обучения.

---

## Группы функционала

### 1. SNP-Search (Поиск и фильтрация SNP)

* **Точечный поиск:** Фильтрация карты по конкретной мутации (SNP) или группе.
* **Временной срез:** Ползунок TMRCA (от -500 до 500) для отсечения ветвей по времени жизни общего предка.
* **Филогенетический контекст:**
    * `Show Sons` — динамическое отображение дочерних (нисходящих) субкладов.
    * `Homeland` — визуализация расчетного ядра/прародины гаплогруппы.
    * `Depth` — фильтрация по глубине ветвления древа.

### 2. Macro-View (Макро-анализ популяций)

* **Популяционный обзор:** Группировка всех доступных SNP в заданном историческом интервале (0 ... -500 TMRCA).
* **Сглаживание флуктуаций:** Агрегация данных для быстрой оценки глобальных генетических трендов без локальных
  искажений выборки.

### 3. GEO-Search (Операции над множествами)

* **Сравнение выборок:** Формирование двух независимых групп популяций (**A ⇄ B**) в расширенном временном диапазоне
  TMRCA (-2000 ... 2000).
* **Математический движок:** Выявление связей между регионами через теоретико-множественные операции:
    * `Union (∪)` — слияние ареалов обеих групп.
    * `Subtraction (\)` — исключение группы Б из А (поиск уникальных линий для региона А).
    * `Intersection (∩)` — поиск общих линий для двух выборок (миграционные коридоры).
    * `Exclusive OR (Δ)` — симметрическая разность (отображение только уникальных SNP для каждой из групп со скрытием
      общих).
